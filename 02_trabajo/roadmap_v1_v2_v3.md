# Roadmap · draft
V0 is the documentation and demonstration preparation stage; it does not replace the three academic prototype versions.
- V1 baseline: preserve existing static app and collect a repeatable demo. Review 1: inspect global inventory, price transparency, vehicle compatibility and user experience; team decides which changes to adopt.
- V2 target: interval booking, local capacity validation, vehicle compatibility, transparent dynamic pricing, amenities/ratings demo and operator configuration. Validate with controlled scenarios.
- Review 2: test capacity edges, stale data, cancellations, operator workflow and customer trust; record human decisions.
- V3 target: resilient core booking, selected check-in/no-show operations, owner analytics and documented risks. Shared transactional storage and Mercado Pago test integration only if feasible; otherwise conceptual and explicitly labeled.
Exit gate each version: evidence, limits, peer review decision and traceable changes. No deployment or paid dependencies without team approval.
